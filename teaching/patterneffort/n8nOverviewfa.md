# n8n Workflow Automation & Integration System
## Pattern Recognition
## Author : Seyyed Mohammad Mousavi

##  چیست ؟ n8n

n8n یک پلتفرم متن‌باز برای اتوماسیون گردش‌کار است که امکان اتصال سرویس‌ها، APIها، دیتابیس‌ها و ابزارهای مختلف را فراهم می‌کند.

نام n8n مخفف عبارت nodemation است و به ساختار مبتنی بر نود آن اشاره دارد.

برخلاف بسیاری از ابزارهای SaaS، این پلتفرم قابلیت نصب روی سرور شخصی را دارد.

این موضوع باعث می‌شود کنترل کامل روی داده‌ها، امنیت و زیرساخت وجود داشته باشد.

کاربردهای اصلی n8n شامل موارد زیر است:

- اتوماسیون بک‌اند
- یکپارچه‌سازی APIها
- همگام‌سازی داده‌ها
- پیاده‌سازی بک‌اند چت‌بات
- ساخت پایپ‌لاین‌های داده
- اتصال مدل‌های هوش مصنوعی

## معماری اصلی n8n

هسته عملکرد n8n بر اساس نودها و ورک‌فلوها طراحی شده است.

اجزای اصلی شامل:

- نودها
- ورک‌فلوها
- تریگرها
- اجرای فرایند
- مدیریت کرِدِنشال‌ها
- وبهوک‌ها

هر ورک‌فلو از مجموعه‌ای از نودهای متصل تشکیل شده است.

هر نود یک وظیفه مشخص را انجام می‌دهد.

داده‌ها به صورت JSON ساختاریافته بین نودها منتقل می‌شوند.

## نحوه عملکرد

ساختار کلی اجرای یک ورک‌فلو:

1. اجرای فرایند با یک تریگر آغاز می‌شود.
2. داده به نود بعدی منتقل می‌شود.
3. پردازش انجام می‌شود.
4. در صورت نیاز سرویس خارجی فراخوانی می‌شود.
5. خروجی ثبت یا ارسال می‌شود.

انواع تریگر:

- وبهوک
- زمان‌بندی
- اجرای دستی
- تریگرهای وابسته به اپلیکیشن

نودهای عملیاتی می‌توانند شامل موارد زیر باشند:

- درخواست HTTP
- اتصال به Google Sheets
- عملیات دیتابیس
- ارسال ایمیل
- پردازش فایل
- اجرای کد جاوااسکریپت
- اتصال به مدل‌های زبانی

## مزایا

متن‌باز بودن  
امکان نصب روی سرور شخصی  
کنترل کامل روی داده‌ها  
قابلیت توسعه‌پذیری بالا  
پشتیبانی قوی از API  
هزینه کمتر نسبت به ابزارهای سازمانی  
مناسب برای پروژه‌های هوش مصنوعی  

## معایب

نیاز به دانش فنی برای پروژه‌های پیچیده  
نیاز به مدیریت سرور در حالت self-host  
پیچیدگی در دیباگ ورک‌فلوهای بزرگ  
نیاز به برنامه‌ریزی برای مقیاس‌پذیری  

## ورک‌فلو چیست؟

ورک‌فلو یک زنجیره منطقی از عملیات خودکار است.

این زنجیره مشخص می‌کند:

- اجرای فرایند چگونه شروع شود
- چه پردازشی انجام شود
- داده چگونه منتقل شود
- خروجی چه باشد

ورک‌فلوها می‌توانند ساده یا پیچیده باشند.

نمونه ساده:

دریافت داده از فرم → ثبت در Google Sheets

نمونه پیچیده:

دریافت ورودی → اعتبارسنجی → پردازش با هوش مصنوعی → ذخیره در دیتابیس → ارسال ایمیل → ثبت لاگ

## ویدیوهای آموزشی

چهار ویدیوی آموزشی برای یادگیری عملی آماده شده است:

1. نحوه ثبت‌نام در n8n  
2. نصب n8n روی لوکال‌هاست  
3. آشنایی با ورک‌فلوها و نحوه استفاده  
4. اتصال به Google Sheets  

توصیه می‌شود ویدیوها به ترتیب مشاهده شوند تا درک مفهومی و عملی کامل حاصل شود.
